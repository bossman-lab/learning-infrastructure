## 底层限制链

```
L1 → L2 → L3 → S4 → S3 → S2 → S1
 │     │     │     │     │     │     │
 睡眠  睡眠  记忆  能量  耐受  诚实  看见
 能量  输入  建模  基线  边界  模糊  自欺
```

当你在某一层卡住时：
- 先检查它下面的所有层——卡住的表现可能在S1，但根因可能在L2或L1
- 从能最快见效的层开始修——L1永远是回报最高的起点
- 不要同时修超过两层——信息过载，坚持不住

## 按场景速查

| 你的问题 | 可能是哪层 | 第一个解法 |
|---------|-----------|-----------|
| 睡醒还是累，上午反应慢 | L1 | 晨间光 |
| 学了记不住，24小时后空白 | L2 | 睡后复习 |
| 知道概念但做不出判断 | L3 | 判断环 |
| 坐下来学不进去，老走神 | S4 | 分钟化 |
| 知道该学但启动不了 | S3 | 动机溯源 |
| 遇到不懂马上查答案 | S2 | 延迟判定 |
| 以为自己懂了但说不出来 | S1 | 三级追问 |
