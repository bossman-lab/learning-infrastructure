# 附录：七层框架与择偶——操作手册

本附录不是理论——是一套你在关系不同阶段可以拿出来用的评估工具。每个工具都不是用来"打分"的，是用来让你在信息充分的情况下做判断的。

---

## 第一部分：三个实地测试（信度最高）

下面三个测试的价值在于：它们不可准备、不可伪装。你在"测试"时不需要让对方知道你在测试。只需要在对应场景出现时，观察她的自然反应。

### 测试一：堵车测试 · 测L1压力基线

**场景**：你们一起开车，被堵在一条不能掉头的路上，预计要等30分钟以上。没有替代路线。

**观察什么**：

她的第一反应是哪一类——

| 层级 | 表现 | 评估 |
|------|------|------|
| A | 啧一声或叹口气，然后调座椅/放音乐/说"那就等着吧" | L1正常：能识别压力、做调节 |
| B | 不断刷导航、换路线、打电话问人，越刷越烦躁 | L1偏高唤醒：压力下调节能力弱 |
| C | 开始指责"你为什么不走另一条路"——即使那条路也堵 | 危险信号：压力下有向外归因/攻击倾向 |

**30分钟内的后续**：

| 表现 | 评估 |
|------|------|
| 聊了别的话题、或者各自安静地看手机/听歌 | 自动调节正常 |
| 反复回到"怎么还堵/要迟到了"的话题 | 调节困难 |
| 情绪蔓延到下一件事——到了目的地还在烦躁 | L1恢复时间长，和她在一起你会耗能 |

**🚩 红旗**：如果堵车30分钟内的反应属于B-C档，且后续无法恢复——她不是今天心情不好，这是她的自主神经系统在不可控压力下的默认模式。你未来几十年在面对育儿、财务危机、健康问题时的"队友状态"就是这种反应。

---

### 测试二：沙发测试 · 测L3默会相容性

**场景**：周五晚上，没有任何安排。可以出门但两个人都不想动。一起坐在沙发上。

**观察什么**：

| 表现 | 评估 |
|------|------|
| 身体自然往对方那边倾斜，不需要找话题填充沉默 | L3相容性高——共享的默会空间够大 |
| 各自刷手机但偶尔分享看到的东西，分享时对方会放下手机听 | L3相容性中——可以积累 |
| 一个人不断找话题，另一个人简短回应；或者其中一人先忍不住拿出手机 | L3相容性低——默会空间还没形成 |
| 坐了半小时，一个人说"要不出去走走"——不是真的想走，是对沉默不耐受 | 🚩 L3相容性低+模糊不耐受 |

**2小时的时长测试**：

如果你们能在一张沙发上待两个小时而不需要做任何"事"——不说话也行、各自看手机也行、中间有10分钟不说话也不尴尬——这是L3相容性达标的标志。这个能力不能被制造，只能被观察到。它说明你们在彼此在场时，默认模式网络不需要切换成"找话题"模式。

**🚩 红旗**：每次两小时独处都需要"做点什么"才能不尴尬——看电影、打游戏、出门吃饭。这些活动本身没问题，但如果去掉这些活动就沉默到让人不舒服——说明你们之间没有默会空间，只有活动填充。

---

### 测试三：吵架测试 · 测S1+S3+S4的修复能力

**场景**：你们真正意义上吵了一架——不是小事拌嘴，是涉及底线或价值观的冲突。

**观察什么——分阶段**：

**吵架中**：

| 表现 | 评估 |
|------|------|
| 注意力（S4）放在"解决问题"上，集中在对方的观点而不是只有"证明我对" | S4正常 |
| 注意力集中在"赢"——打断对方、反复同一句话 | S4偏窄——关系中的注意力模式是攻击性 |
| 能说"等一下，我刚才说的不是这个意思" | S1存在——能实时监测自己的表达和意图是否一致 |
| 吵到一半突然沉默，不是因为认输，是不想吵了——然后问题也没解决 | 🚩 S2低模糊耐受——用回避代替解决 |

**吵架后（最关键）**：

| 表现 | 评估 |
|------|------|
| 吵完半小时到一小时后，其中一个人主动说"刚才那件事，我们复盘一下？" | S3动机是解决问题——这是最好的信号 |
| 冷战，等到第二天当没事发生 | S3动机是回避冲突——问题会重复发生 |
| 冷战，必须一方先道歉才能恢复对话 | 🚩 关系中的S3变成了"谁先低头"的权力游戏 |
| 吵架后再也不谈这个话题，但行为上有改变 | S3动机是"我知道错了但我不愿承认"——也可以用，但沟通成本高 |

**修复的质量**：

能说"我刚刚反应过度了，不是因为这件事，是因为我今天状态不好"的人——是S1+S3都在工作。她在用元认知识别自己的模式，动机是修复关系。

不能说"对不起"三个字的人——不是性格倔，是S3动机中"认错=丢脸的损失"大于"修复关系的收益"。这是最难处理的模式，因为修复的前提（主动开口）被心理机制封锁了。

**🚩 红旗**：如果连续三次吵架后，都是你先开口道歉，或者问题从来不解决——这不是"她脾气倔"，是她的S3动机结构不支持健康的冲突后修复模式。你会长期承担关系中的修复成本。

## 第二部分：阶段观察清单（按关系时长）

### 第一个月：L1底色 + S3初筛

| 观察项 | 方法 | 注意 |
|--------|------|------|
| 怎么对待服务人员/司机/店员 | 约会在餐厅/打车时自然观察 | 这是未经修饰的L1反应 |
| 怎么谈论前任 | 聊天中自然提到 | S1: 是反思模式还是指责模式 |
| 计划改变时的第一反应 | 故意制造一个小的计划调整 | L1压力基线 |
| "你为什么想认识我"的回答 | 直接在聊天中问 | S3动机的第一层你天然就观察得到 |

**可做动作**：在这个阶段主动创造一次"小堵车"情境——约在地铁附近但告诉她"突然不想坐地铁了，我们走过去吧"——观察她面对计划外走路20分钟的适应速度。

### 1-3个月：L2匹配 + S2模糊耐受

| 观察项 | 方法 | 注意 |
|--------|------|------|
| 旅行一次的配合度 | 安排一次短途旅行（2天1夜） | L2的最佳测试场——行程变动时的协调 |
| 你们各自沉默时是否舒适 | 家中独处，不做任何"安排" | 沙发测试可以开始了 |
| 谈未来时她的状态 | 聊半年后、一年后的事 | S2模糊耐受——有明确答案还是一直追问 |
| 聊天节奏是否匹配 | 日常微信/面对面聊天 | 你讲长句子时她会听完吗？她是否经常打断？ |

**可做动作**：策划一次短途旅行，选择目的地时要有一件不可控因素（比如天气预报有雨）。从行程安排开始你们就开始进入首次协调测试。

### 3-12个月：S1元认知 + 第一次吵架测试

**在这个阶段前你一定会吵一次有意义的架。给它机会发生——不要为了"维持关系"回避所有冲突。**

| 观察项 | 方法 | 注意 |
|--------|------|------|
| 第一次重大分歧的解决模式 | 让分歧自然发生 | 看上述"吵架测试"的完整过程 |
| 她是否能说"我错了" | 当她确实错了的时候 | 这是S1+S3的联合测试 |
| 她讲自己成长经历时的归因模式 | 深入了解她的家庭和过去 | 倾向"环境塑造了我"还是"都是他们的错" |
| 她是否有自己的注意力和兴趣的投入重心 | 观察她对爱好/工作的投入 | S4注意力分配——她能把注意力放在自己和自己的事情上吗？ |

**🚩 红旗**：在这个阶段前你如果发现她完全没有自己投入的事（除了关系之外），她的S4注意力有极大可能是因为她把全部注意力放在关系上——这在初期让你觉得被重视，长期会让你感到沉重。

### 1-2年：L3建设方向测试

| 观察项 | 方法 | 注意 |
|--------|------|------|
| 一年后你们有了多少"只有你们懂的"内部语言/默契 | 自然积累 | L3共享默会知识的存量 |
| 一起做一件需要合作的复杂事的结果 | 一起装修/搬家/照顾宠物/做旅行计划 | L3的真实场 |
| 吵完重大架后，关系是否比以前更好 | 回顾你的感受 | 修复后的关系质量——修复不只是回到原状 |

**🚩 红旗**：一年后你们没有发展出任何共享内部语言，每次旅行/搬家都带来巨大压力，重大冲突从未修复——你们的L3方向不一致。这个不会随时间变好。

## 第三部分：不可妥协的红旗

以下条件如果你在任一阶段中观察到，**不建议继续发展**。不是因为"她不够好"——是因为这些层的问题会在长期关系中持续消耗你，且改变极其困难：

| 层 | 红旗信号 | 为什么难改 |
|----|---------|-----------|
| L1 | 压力下向外攻击（指责、摔东西、对陌生人发火） | L1基线是自主神经系统的设置，改不了 |
| S1 | 从未说过"我错了" | 元认知缺失——无法看见自己模式的人无法改变模式 |
| S3 | 和你在一起的理由全是外部条件（条件、安全感、年龄） | 动机不来自内部，外部条件变了就没了 |
| S4 | 和你在一起时注意力永远在别处（手机、工作、别人） | 注意力分配是长期习惯，很难被"沟通"改变 |
| 跨层 | 你发现自己在这段关系中比单身时更焦虑、消耗、不自信 | 关系是L1+S1-S4的共调节环境，你在变薄就不是好环境 |

## 第四部分：权衡框架——没有完美的人

所有人都有弱项。关键是：**你的弱项和对方的弱项是否在兼容的层上。**

示例：

| 你的弱项 | 对方的弱项 | 相容性 |
|---------|-----------|--------|
| L1偏高唤醒（你容易被压力带跑） | L1调节能力强（她在压力下稳定） | ✅ 互补——她可以帮你调L1 |
| L1偏高唤醒（你容易被压力带跑） | L1偏高唤醒（她压力下比你还不稳定） | ❌ 共振——你们会把对方的压力放大 |
| S3好奇+需要驱动（你因为真心喜欢和她在一起） | S3好奇+需要驱动（她也因为真心喜欢和你在一起） | ✅ 对上了，方向一致 |
| S3好奇驱动 | S3恐惧驱动（她说和你在一起是因为怕找不到更好的） | ❌ 不对等——你投入的动机层级比她深 |
| S2模糊耐受差（你总需要一个答案） | S2模糊耐受中等 | ⚠️ 可调——你需要在不确定的事情上学会让对方有思考空间 |
| S1存在（你能看到关系中的模式） | S1缺失（她看不到自己的模式） | ⚠️ 不对称——你会成为关系中唯一的调试器 |

**一个核心原则**：有S1的人（能看见自己模式的人）即使其他层有弱项，也有可能通过时间慢慢调整。S1缺失的人，即使其他层看起来很好，长期会由她无法自察的模式卡住关系。

---

## 第五部分：使用说明

1. **不要拿着这个清单去"考察"对方。** 信任感是关系的基础——你在给人打分的感觉会破坏它。这套工具是给你自己用的——在关系自然进展的过程中，你心里有数，知道哪些信号该注意。

2. **观察时间越长越好。** L1压力基线和S1元认知需要足够多的压力场景才能暴露。三个月以内的行为基本都是展示面。

3. **你的弱项也在被测试。** 这套框架是双向的。你对堵车烦躁的时候，对方也在观察你。关系不是单方向的选择——是两个学习基础设施之间的交互。

4. **"和这个人在一起十年后，我的学习系统是变得更厚了，还是更薄了？"** 这是唯一一个你需要诚实地回答自己的问题。如果你发现这段关系让你说话更小心、精力更少、对未来的安全感更低——不是你的问题，是你的L1正在被消耗。
