# 学习的基础设施

**为什么方法对了还是学不快？**

「AI时代：从恐惧到不可替代」系列 · L3（效率恐惧）

---

## 这本书解决什么问题

你有正确的学习方法——知道要写预测日志、要找融汇点、要做参数实验。但效果就是不如预期。

不是你的方法有问题。是你的学习操作系统跑在一个不稳定的基础设施上。

这本书不教你新的学习方法。它帮你看见你的学习能力由哪些层构成——每个层是什么、什么在限制它、能不能培养、怎么培养——然后你卡住的时候知道该修哪一层。

## 两套栈

**软件栈（S1-S4）**——你用什么样的认知模式在学
- S1 元认知：你能看见自己的理解吗？
- S2 模糊耐受：你能忍受「不懂」的状态吗？
- S3 动机结构：你为谁而学？
- S4 注意力架构：你能在一条线上待多久？

**硬件栈（L1-L3）**——你的身体能不能支持大脑高效运行
- L1 身体基础：你的大脑跑在什么硬件上
- L2 神经效率：大脑的物理连接质量
- L3 认知体验：从「知道」到「有实感」

**每一层限制上一层的上限。** 不是影响——是限制。

## 阅读方式

**如果卡住了：** 翻到Part 2对应层的自测部分，确认是哪层的问题，然后读该层的培养方法。

**如果想系统读完：** 从Part 1开始 → Part 2（七层全部读完）→ Part 3（挑你感兴趣/卡住的学科深化）→ Part 4（读你现在所在的年龄段 + 下一阶段）。

**如果时间不够：** 读Ch0（框架）→ 读你现在年龄段的那一章（Part 4）→ 按照里面的优先级修对应的层。
