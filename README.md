# 学习的基础设施

**为什么方法对了还是学不快？**

「AI时代：从恐惧到不可替代」系列 · L3（效率恐惧）

---

## 这本书解决什么问题

你有正确的学习方法——知道要写预测日志、要找融汇点、要做参数实验。但效果就是不如预期。

不是你的方法有问题。是你的学习操作系统跑在一个不稳定的硬件上。

这本书不教你新的学习方法。它帮你检查你的学习系统跑在什么上，以及当方法失效时，往下看哪一层。

## 两套栈

**软件栈（S1-S4）**——你用什么样的认知模式在学
- S1 元认知：你能看见自己的理解吗？
- S2 认知品格：你能忍受"不懂"的状态吗？
- S3 动机结构：你为谁而学？
- S4 注意力架构：你能在一条线上待多久？

**硬件栈（L1-L3）**——你的身体能不能支持大脑高效运行
- L1 身体基础：你的大脑跑在什么上
- L2 神经效率：大脑的物理连接质量
- L3 认知体验：从"知道"到"有实感"
